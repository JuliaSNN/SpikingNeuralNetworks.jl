# SpikingNeuralNetworks.jl

[![CI](https://github.com/JuliaSNN/SpikingNeuralNetworks.jl/workflows/CI/badge.svg)](https://github.com/JuliaSNN/SpikingNeuralNetworks.jl/actions)
[![docs](https://img.shields.io/badge/docs-dev-blue.svg)](https://juliasnn.github.io/SpikingNeuralNetworks.jl/dev/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Simulate networks of spiking neurons in Julia. Install with `] add SpikingNeuralNetworks` and start
with [Getting started](https://juliasnn.github.io/SpikingNeuralNetworks.jl/dev/getting_started/).

Upgrading from version 1: see
[What changes from v1 to v2](https://juliasnn.github.io/SpikingNeuralNetworks.jl/dev/#What-changes-from-v1-to-v2).
