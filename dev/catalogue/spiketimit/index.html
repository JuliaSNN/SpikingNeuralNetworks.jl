SNNUtils: Spike TIMIT speech inputs

SNNUtils.SpikeTimit reads the Spike TIMIT corpus and turns real speech into inputs for SNNModels networks. Load it with

using SNNUtils
using SNNUtils.SpikeTimit      # its names are not exported into SNNUtils
using MAT                      # only needed to read BAE spike files

What Spike TIMIT is

Spike TIMIT is the TIMIT speech corpus converted into spike trains by auditory encoders. Every sentence comes with a word transcription, a phone transcription and spike times.

Licence

The audio and transcriptions come from TIMIT (LDC93S1), which is licensed by the Linguistic Data Consortium and cannot be redistributed. Neither SNNUtils nor these docs contain corpus data. You need your own licensed copy of the corpus and of the spike files generated from it. The tests of SNNUtils use a small invented corpus with the same file formats.

SpikeTimit provides:

  • readers of the transcriptions and of the spike files (create_dataset, get_spiketimes);
  • selection of words and sentences (find_word, select_words);
  • processing of spikes (resample_spikes!, transform_into_bursts!, select_frequencies!, remove_frequencies!);
  • stacking of utterances into long inputs (get_ordered_spikes);
  • conversion to SNNModels stimuli and SNNUtils sequences (spiketime_parameter, to_sequence, label_intervals).

Dataset layout and SPIKETIMIT_PATH

The corpus location is the argument dir of the functions, or, if it is not given, the directory named by the environment variable SPIKETIMIT_PATH:

export SPIKETIMIT_PATH=/data/SpikeTIMIT
dataset_path()                   # the root: ENV["SPIKETIMIT_PATH"]
dataset_path("train")            # root/train
dataset_path("DOC", "TIMITDIC.TXT")

A missing variable gives an ArgumentError that names it. The expected layout (lowercase names):

SpikeTIMIT/
  DOC/TIMITDIC.TXT                         pronunciation dictionary
  train/dr<k>/<speaker>/<senID>.wav        marks a sentence (the audio is not read by Julia)
  train/dr<k>/<speaker>/<senID>.wrd        words:  "<t0> <t1> <word>"  (samples at 16 kHz)
  train/dr<k>/<speaker>/<senID>.phn        phones: "<t0> <t1> <phone>"
  train/dr<k>/<speaker>/<senID>_spike_timing.mat    BAE spikes
  train/dr<k>/<speaker>/<senID>_cochlea35.npz       cochlea spikes, 35 channels
  train/dr<k>/<speaker>/<senID>_cochlea70.npz       cochlea spikes, 70 channels
  test/...                                 same structure

k is the dialect region (1 to 8); the first letter of the speaker name is the gender (f or m). create_dataset walks train/ or test/ and returns a DataFrame with one row per sentence (columns speaker, senID, dialect, gender, path, words, phones, sentence); words and phones are Transcriptions. Spike files are read only when asked for.

Encodings

EncodingFileChannelsNeeds
BAE()<path>_spike_timing.mat620 (20 bands x 31 threshold neurons)using MAT
Cochlea(35), Cochlea(70)<path>_cochlea35.npz, <path>_cochlea70.npz35, 70nothing

The BAE files (threshold encoding of Pan et al., 2020) are read through a package extension: without using MAT, reading them throws an error that says so. The raw BAE times are multiplied by SpikeTimitConfig().correction (5) to give seconds. A cochlea file holds one array arr_0 of size 2 x K: row 1 the spike times, row 2 the 0-based channel of each spike; the times are taken as seconds.

encoding also accepts the strings "bae", "cochlea35" and "cochlea70".

Transcription times are the sample indices of the files divided by the sample rate of SpikeTimitConfig (16 kHz). Convert only at the boundary to SNNModels: a spike train in seconds passed to a population in ms would run 1000 times too fast.

Workflow

using SNNUtils, SNNUtils.SpikeTimit, MAT
import SNNModels
using Random

rng = MersenneTwister(1)

# 1. the sentences of the corpus
train = create_dataset(dataset_path("train"))

# 2. utterances of two words, at most 10 sentences per word (without replacement)
inputs = select_words(train, ["that", "she"]; encoding = BAE(), samples = 10, rng)
resample_spikes!(inputs.spikes; n_feat = 8)            # BAE: 620 -> 80 channels
transform_into_bursts!(inputs.spikes; rng)

# 3. one long input: every utterance 5 times, random order, 100 ms of silence in between
ids = mix_inputs(rng, length(inputs.durations), 5)
ordered, trans = get_ordered_spikes(inputs; ids, silence_time = 0.1, shift = 0.0)   # seconds

# 4. a stimulus for an SNNModels population (Float32, ms)
E = SNNModels.IF(N = 200)
stim = SNNModels.SpikeTimeStimulus(E, :ge; param = spiketime_parameter(ordered),
                                   conn = (p = 0.1, μ = 2.0),
                                   N = get_encoding_dimension(inputs.spikes))
model = SNNModels.compose(; E, stim)

# 5. word and phone timing as an SNNUtils sequence (Float32, ms)
seq = to_sequence(trans)
SNNModels.sim!(; model, duration = SNNUtils.sequence_end(seq))

Pass N to SpikeTimeStimulus explicitly. By default it is the largest neuron index that fires, which undercounts the input channels if the highest ones never fire.

select_words samples sentences without replacement; replace = true samples with replacement. get_ordered_spikes needs either ids or repetitions.

Relation to SNNUtils sequences

SNNUtils generates synthetic word and phoneme sequences (generate_sequence) and locks stimuli to their intervals (sign_intervals, update_stimuli!). SpikeTimit supplies the real counterpart:

  • to_sequence builds a sequence with the fields of a synthetic one from the word and phone transcriptions of a stacked input, so sign_intervals, all_intervals, merge_intervals, sequence_end, stimuli_names and update_stimuli! work on real speech. Every word occurrence is separated from the previous one by a silence element, so two consecutive utterances of the same word are two presentations.
  • label_intervals(trans.words, "that") gives the intervals of one label as Vector{Vector{Float32}} in ms, the format of SNNModels.set_intervals!.
trans.words                                    # Transcription{Float64}, seconds
label_intervals(trans.words, "that")           # [[t0, t1], ...] in ms
seq = to_sequence(trans)
SNNUtils.sign_intervals(:that, seq)            # the same intervals, from the sequence

A word spelled like a phone label (a word ah and a phone ah) is looked up as the phone by sign_intervals; to_sequence warns once about such collisions.

SNNUtils.SpikeTimit — Module
SpikeTimit

Reader of the Spike TIMIT corpus: real speech inputs (spike trains with word and phone timing) for SNNModels networks.

Spike TIMIT is the TIMIT corpus encoded into spike trains by auditory models: the BAE threshold encoding (BAE, .mat, needs using MAT) and cochlea models (Cochlea, .npz). The corpus is licensed (LDC) and not distributed: give its location with ENV["SPIKETIMIT_PATH"] or explicit paths (dataset_path).

Workflow: create_dataset -> find_word / select_words -> resample_spikes!, transform_into_bursts! -> get_ordered_spikes -> spiketime_parameter (input of SNNModels.SpikeTimeStimulus) and to_sequence / label_intervals (word/phone timing).

Units

  • Data functions use Float64 SECONDS: transcription times are sample indices divided by SpikeTimitConfig().sr (16 kHz); spike trains are SpikeTrains{Float64}.
  • Conversion functions (to_snn_spiketimes, spiketime_parameter, ms_intervals, label_intervals, to_sequence) return Float32 MILLISECONDS, the SNNModels convention.
  • transcriptions_dt and ft_dt return integer time steps (dt in ms).

[DEPRECATED] Python TIMIT tools

The Python tools of the former SpikeTimit.jl repository (TIMIT_loader/) are not part of SNNUtils and are no longer maintained: the pandas DataFrame of the TIMIT sentences and the constant-Q (CQT) spectra per word and phone computed with librosa, which fed the spectra example through PythonCall. SNNUtils has no replacement for these functions; it reads the spike encodings only. The last copy of the tools is the folder TIMIT_loader/ of the (archived) SpikeTimit.jl repository.

Relation to SNNUtils sequences

SNNUtils generates synthetic word/phoneme sequences (generate_sequence) and drives stimuli locked to their intervals (sign_intervals, update_stimuli!). to_sequence builds a sequence with the same fields from real TIMIT timing, so those functions work unchanged on speech; label_intervals gives the same Vector{Vector{Float32}} interval format.

The names are exported by SpikeTimit only: use using SNNUtils.SpikeTimit.

SNNUtils.SpikeTimit.SpikeTimitConfig — Type
SpikeTimitConfig(; sr = 16000.0, correction = 5.0, bae_frequencies = 20, bae_bins = 31)

Constants of the Spike TIMIT corpus, passed explicitly to the functions that need them (they replace the global variables of the old SpikeTimit.jl package). Immutable and isbits.

Fields

  • sr::Float64 = 16000.0: sample rate (Hz) of the sample indices in the .wrd/.phn files; transcription times (s) are sample / sr.
  • correction::Float64 = 5.0: dimensionless factor applied to the raw spike times of the BAE .mat files to obtain seconds (raw * correction).
  • bae_frequencies::Int = 20: frequency bands of the BAE encoding.
  • bae_bins::Int = 31: threshold neurons per band; the BAE encoding has bae_frequencies * bae_bins (620) channels, band-major.

Throws an ArgumentError unless sr > 0, correction > 0, bae_frequencies >= 1 and bae_bins >= 1.

Examples

julia> using SNNUtils.SpikeTimit

julia> SpikeTimitConfig(sr = 8000).sr
8000.0

SNNUtils.SpikeTimit.resample_spikes! — Method
resample_spikes!(st; n_feat::Int = 8, config = SpikeTimitConfig())
resample_spikes!(batch; n_feat::Int = 8, config = SpikeTimitConfig()) -> batch

Merge the threshold neurons of each frequency band of a BAE encoding (BAE only).

Within each of the F = config.bae_frequencies bands, the B = config.bae_bins threshold channels are grouped by n_feat: channel b of band f goes to output channel ceil(Int, b / n_feat) + (f - 1) * nb, with nb = ceil(Int, B / n_feat) channels per band (620 -> 80 channels for n_feat = 8). Spike times (s) of a group are concatenated in channel order, not sorted.

Arguments

  • st: spike trains of one sample with F * B (620) channels.
  • batch: vector of samples; each element is replaced by its resampled version.
  • n_feat::Int = 8: channels merged per group, in 1:11.
  • config::SpikeTimitConfig: BAE band geometry.

Returns

  • One sample: a NEW SpikeTrains{Float64} with F * nb channels; st itself if n_feat == 1.
  • Batch: the mutated batch.

Throws an ArgumentError if n_feat is not in 1:11 or length(st) != F * B.

Examples

using SNNUtils.SpikeTimit, MAT
spikes = select_words(df, ["that"]; encoding = BAE()).spikes
resample_spikes!(spikes; n_feat = 8)      # every sample now has 80 channels

See also transform_into_bursts!.

SNNUtils.SpikeTimit.transform_into_bursts! — Method
transform_into_bursts!(st; spikes_per_burst_increase::Int = 0, rng = Random.default_rng()) -> st
transform_into_bursts!(batch; spikes_per_burst_increase::Int = 0, rng = Random.default_rng()) -> batch

Turn every spike into a burst, in place.

For each original spike at t (s) a burst size v is drawn from [2, 3, 4, 5, 6] .+ spikes_per_burst_increase with probabilities proportional to [0.8, 0.15, 0.075, 0.035, 0.03] (Oswald, Doiron & Maler 2007, Fig. 1B, 0.7 nA), and v - 1 spikes are added at t + 0.004 + 0.005 * randexp(rng) (s: 4 ms plus an exponential delay of mean 5 ms). Each non-empty channel is then sorted; empty channels are untouched.

Arguments

SNNUtils.SpikeTimit.to_sequence — Method
to_sequence(trans::Transcriptions{Float64}; tail::Real = 0.0) -> NamedTuple

Build an SNNUtils sequence from real word and phone timing (s), so that the SNNUtils sequence functions (sign_intervals, merge_intervals, all_intervals, sequence_end, stimuli_names, update_stimuli!, set_stimuli!) work on TIMIT speech.

Each word becomes a run of elements (word, phone, duration): one per phone, plus (word, :_) elements for the gaps between phones. Every word is preceded by a silence element (:_, :_) (also of zero duration, so that repeated words stay separate presentations) and the sequence ends with a silence of tail s. Durations are converted to Float32 ms; onsets and offsets are their cumulative sums (Float32 accumulation: drift < 1e-3 ms for sequences < 100 s).

Arguments

  • trans::Transcriptions{Float64}: words and phones (s), e.g. from get_ordered_spikes. Words must be sorted and non-overlapping; every phone must lie inside a word (phones outside words, such as h# or pau of a raw sentence, must be removed first), sorted and non-overlapping.
  • tail::Real = 0.0: silence (s) after the last word, >= 0.

Returns

NamedTuple with the fields of SNNUtils.generate_sequence:

  • dict::Dict{Symbol,Vector{Symbol}}: phones of the first occurrence of each word;
  • symbols = (phonemes, words): sorted unique symbols (silence :_ excluded);
  • ph_duration::Dict{Symbol,Float32}: mean duration (ms) of each phone and of silence (informational);
  • silence = :_;
  • sequence::Matrix{Any}: 6 x n, rows words, phonemes, duration (ms), type (:onset, :offset_j, :offset, :silence), onset (ms), offset (ms);
  • line_id = (words = 1, phonemes = 2, duration = 3, type = 4, onset = 5, offset = 6).

Throws an ArgumentError if the preconditions above are violated or tail < 0.

Warning

SNNUtils.sign_intervals looks a symbol up among the phonemes first: a word spelled like a phone label resolves to the phone. to_sequence warns about such collisions.

Examples

using SNNUtils, SNNUtils.SpikeTimit
spikes, trans = get_ordered_spikes(inputs; silence_time = 0.1, shift = 0.0, repetitions = 2)
seq = to_sequence(trans; tail = 0.2)
SNNUtils.sign_intervals(:that, seq)     # ms, same as label_intervals(trans.words, "that")
SNNUtils.sequence_end(seq)             # simulation length, ms

See also label_intervals, spiketime_parameter.
