Multicompartment neurons

Tripod (AdEx soma, two passive dendrites d1, d2), BallAndStick (one dendrite d) and Multipod (1 to 64 dendrites d1, ..., dN). The soma is an adaptive exponential integrate-and-fire neuron; the dendrites are passive cables with leak, synaptic currents (AMPA, NMDA, GABA) and axial coupling to the soma.

A connection selects the compartment (:s, :d1, :d2; :s, :d) with its fourth argument:

using SpikingNeuralNetworks
SNN.@load_units
T = SNN.Tripod(N = 10)
E = SNN.Poisson(N = 50, param = SNN.PoissonParameter(20Hz))
I = SNN.Poisson(N = 50, param = SNN.PoissonParameter(20Hz))
E_d1 = SNN.SpikingSynapse(E, T, :glu, :d1; conn = (p = 0.2, μ = 2.0))   # first dendrite
E_d2 = SNN.SpikingSynapse(E, T, :glu, :d2; conn = (p = 0.2, μ = 2.0))   # second dendrite
I_s  = SNN.SpikingSynapse(I, T, :gaba, :s; conn = (p = 0.2, μ = 2.0))   # soma
model = SNN.compose(; E, I, T, E_d1, E_d2, I_s)
SNN.monitor!(T, [:v_s, :v_d1, :v_d2, :fire])
SNN.sim!(; model, duration = 500ms)

Equations

For dendrite $k$ ($k = 1, 2$ for Tripod, $k = 1$ for BallAndStick), with somatic parameters from adex and spike parameters from spike:

\[\begin{aligned} C \frac{dV_s}{dt} &= g_L (E_L - V_s) + g_L \Delta_T\, e^{(V_s - \theta)/\Delta_T} - w_s - I_{syn,s} - \sum_k g_{ax,k}\,(V_s - V_{d,k}) + I \\ C_{d,k} \frac{dV_{d,k}}{dt} &= g_{m,k} (E_{L,k} - V_{d,k}) - I_{syn,d,k} + g_{ax,k}\,(V_s - V_{d,k}) + I_d \\ \tau_w \frac{dw_s}{dt} &= a (V_s - E_L) - w_s \\ \tau_A \frac{d\theta}{dt} &= V_t - \theta \end{aligned}\]

$I_{syn}$ are the currents of the synapse models (clamped to $\pm 1500$ pA in Tripod, $\pm 1000$ pA in BallAndStick); $C_{d,k}$, $g_{m,k}$, $g_{ax,k}$ come from create_dendrite.

A spike is emitted when $V_s$ reaches Vspike (default $0$ mV): $V_s$ is held at spike.AP_membrane for spike.up, then at adex.Vr for spike.τabs; $w_s \mathrel{+}= b$, $\theta \mathrel{+}= A_t$. During the back-propagation (up) and refractory (τabs) periods the dendrites are integrated in full (leak, synapses, axial current, external input) with the soma held at its clamp value, and $w_s$ is frozen. Vspike is compared with the predicted potential.

Integration: Heun method on $(V_s, V_{d,k}, w_s)$ (scheme = HeunScheme(), second order between spikes): the synaptic conductances are advanced once per step with the exact exponential update, then $k_1 = f(x_n)$ and $k_2 = f(x_n + dt\,k_1)$ are evaluated with every term, synaptic currents included, at the stage state, and $x_{n+1} = x_n + dt (k_1 + k_2)/2$. $\theta$ relaxes by forward Euler. The spike and refractory counters are round(up / dt) and round(τabs / dt) steps. The split scheme of the published code is PaperScheme, see TripodPaper.

Tripod

Reference: Quaresima, Fitz, Duarte et al. (2023), The Tripod neuron: a minimal structural reduction of the dendritic tree, J. Physiol. 601:3265-3295, 10.1113/JP283399.

using SpikingNeuralNetworks
SNN.@load_units
T = SNN.Tripod(N = 10, param = SNN.TripodParameter(ds = SNN.random_proximal_distal),
               adex = SNN.AdExParameter(b = 0pA, a = 0nS))
T.I .= 300pA

SNN.sim!([T]; duration = 200ms)
Implementation note

The exponential term of the soma carries $g_L$ ($g_L \Delta_T e^{(V-\theta)/\Delta_T}$), as in the published code and in AdEx; Eq. 1 of the preprint omits it. The default scheme detects the spike on the predicted potential against Vspike (0 mV); the published code tests the potential at the start of the step (PaperScheme, TripodPaper). The adaptation current is unbounded and has no reversal, so the somatic potential undershoots after a burst (about -130 mV after 46 spikes under 3 nA); nothing is clipped, as in AdEx.

SNNModels.PaperScheme — Type
PaperScheme(; AP_spike = 21mV)

Integration scheme that reproduces the published Tripod code (aquaresima/tripod_neuron, commit 8698e1a, simulator/simulation.jl) step by step; selected by TripodPaper. It differs from HeunScheme in the following (all of them checked against that code, see validation/tripod_audit of the JuliaSNN publication repository):

  • order of operations in a step: external currents added as an Euler kick dt I / C to the potentials; synapses advanced; then, per neuron, the spike test V_s >= Vspike on the potential at the start of the step (not on a prediction);
  • free integration: the axial currents are computed once from the potentials at the start of the step and kept fixed in both stages; each dendrite takes a two-stage Heun step with them; w_s takes a forward-Euler step with the old V_s; then the soma takes a two-stage Heun step with the new w_s and the fixed axial currents; the exponential term uses exp32o; the somatic synaptic current is not clamped (the dendritic ones are, at ±1500 pA);
  • spike: V_s is set to AP_spike, w_s += b, the dendrites are not integrated in the spike step;
  • backpropagation and refractory period: the dendrites are integrated in full against the somatic potential stored from the previous step (so the clamp acts with one step of delay, as in the original), then V_s is set to spike.AP_membrane (backpropagation) or adex.Vr (refractory);
  • Vspike is the threshold of the spike test (the original uses the exponential-term threshold, adex.Vt).

With spike = PostSpike(up = 1ms, τabs = 2.1ms) and dt = 0.1 ms the spike step, 9 backpropagation steps and 21 refractory steps of the original are obtained. The scheme is tuned to dt = 0.1 ms; other steps give a warning (once).

Field

  • AP_spike::Float32 = 21mV: somatic potential on the spike step (the following backpropagation steps use spike.AP_membrane, 20 mV in TripodPaper).

SNNModels.Tripod — Type
Tripod(; N = 100, param = TripodParameter(), adex = AdExParameter(),
         soma_syn = TripodSomaSynapse, dend_syn = TripodDendSynapse, spike = PostSpike(), ...)

Population of three-compartment neurons: an AdEx-like soma coupled to two passive dendrites (d1, d2) through axial conductances. The dendritic geometry and cable properties are given by param (a DendNeuronParameter), the somatic parameters by adex, the somatic and dendritic synapses by soma_syn and dend_syn (any AbstractSynapseParameter with a five-argument synaptic_current!, i.e. not DeltaSynapse).

Connections select the compartment with the fourth argument of SpikingSynapse: SpikingSynapse(pre, T, :glu, :d1; conn), with targets :s, :d1, :d2.

Equations

Soma (AdEx-like, parameters from adex, an AdExParameter), for each dendrite $k$:

\[\begin{aligned} C \frac{dV_s}{dt} &= g_L (E_L - V_s) + g_L \Delta_T\, e^{(V_s - \theta)/\Delta_T} - w_s - I_{syn,s} - \sum_k g_{ax,k}\,(V_s - V_{d,k}) + I \\ C_{d,k} \frac{dV_{d,k}}{dt} &= g_{m,k} (E_{L,k} - V_{d,k}) - I_{syn,d,k} + g_{ax,k}\,(V_s - V_{d,k}) + I_d \\ \tau_w \frac{dw_s}{dt} &= a (V_s - E_L) - w_s \\ \tau_A \frac{d\theta}{dt} &= V_t - \theta \end{aligned}\]

$I_{syn,s}$ and $I_{syn,d,k}$ are computed by synaptic_current! of soma_syn and dend_syn with the compartment potentials of the Heun stage being evaluated, and are clamped to $\pm 1500$ pA (Tripod) or $\pm 1000$ pA (BallAndStick). $C_{d,k}$, $g_{m,k}$, $g_{ax,k}$ and the dendritic leak reversal $E_{L,k}$ come from the Dendrite structs (see create_dendrite); by default $E_{L,k}$ is the somatic $E_L$ (adex.El), unless param.El_dend is set (a number, mV; it then stays fixed whatever adex.El). $E_{L,k}$ is read at construction: changing adex.El of an existing population moves the somatic leak and the adaptation coupling, not the dendritic leak (d1.El, d2.El; set those directly to change it). The exponential term is multiplied by $g_L$, as in the AdEx model (Brette and Gerstner 2005) and in the code of the published Tripod model (equations.jl of aquaresima/tripod_neuron: gl * (-v + Er + ΔT * exp(...))). Eq. 1 of the bioRxiv preprint of that paper (Quaresima et al. 2023, J. Physiol.) prints the exponential term without $g_L$, which is not the equation the code integrates.

Hyperpolarisation after a burst. The adaptation $w_s$ is a current without reversal potential (as in the AdEx model of Brette and Gerstner 2005; the AdEx populations behave the same): each spike adds b and it decays with τw, so that after a strong burst the somatic potential relaxes to $E_L - w_s/g_L$ and undershoots $E_L$ by $w_s/g_L$ before $w_s$ has decayed. With the default parameters (b = 80.5 pA, τw = 144 ms, gl = 40 nS) a 200 ms drive that makes the soma fire 46 spikes gives $w_s \approx 3000$ pA and a minimum of about -130 mV some 25 ms after the end of the drive; -225 mV corresponds to $w_s \approx 6200$ pA, i.e. a firing rate of several hundred Hz sustained for hundreds of ms (the refractory clamp limits the rate to 1/(up + τabs)). This is the model, not a numerical artefact (the minimum does not depend on dt: -129.8 mV at 0.025 ms, -131.4 mV at 0.5 ms), and the undershoot is bounded by $E_L - w_{max}/g_L$. Nothing in Tripod clips $V_s$ from below; for a bounded afterhyperpolarisation lower b or the input rate.

Spike: when the predicted somatic potential $V_s + dt\,\dot V_s$ reaches Vspike (population field, default $0$ mV, was $-10$ mV before 2.1.0; adex.Vt is only the resting value of $\theta$), the neuron fires: $V_s \leftarrow$ AP_membrane, $w_s \leftarrow w_s + b$, $\theta \leftarrow \theta + A_t$, and the refractory counter is set to n_up + n_abs steps, with n_up = max(1, round(up/dt)) and n_abs = max(1, round(τabs/dt)). The soma is clamped at AP_membrane until the counter reaches n_abs (back-propagation period; the spike step itself counts as one), then at adex.Vr for n_abs steps. In both periods $w_s$ is not integrated, and the dendrites are integrated in full (leak, all synaptic currents including NMDA, axial current, external current) with the same Heun scheme as in free integration, the soma being held at its clamp value in both stages; the dendrites do not move on the spike step itself. (Up to SNNModels 2.0 the dendrites only relaxed axially towards the clamped soma in these periods, without leak and synaptic currents, so that a somatic spike could end an NMDA plateau; see the changelog of 2.1.0.) $\theta$ relaxes to adex.Vt at every step (forward Euler). The published Tripod code (TripodNeuron.jl) detects spikes differently: it fires when $V_s \ge V_T$ on the potential at the start of the step, before integrating, so that Vspike = adex.Vt does not reproduce it (this model fires about one step earlier). The rule, the refractory sequence and the numerics of the published code are available as scheme = PaperScheme() (see TripodPaper).

Integration

Heun (explicit trapezoidal) method on $x = (V_s, V_{d,k}, w_s)$. Synaptic conductances are advanced first, once per step, by update_synapses!. Then $k_1 = f(x_n)$ is evaluated at the current state (stored in Δv_temp) and $k_2 = f(x_n + dt\,k_1)$ at the Euler-predicted state (stored in Δv); every term of $f$, including the synaptic currents, the axial currents and the adaptation current in the somatic equation, is evaluated at the same stage state. The state is advanced by $x_{n+1} = x_n + \frac{dt}{2}(k_1 + k_2)$. The scheme is second-order accurate between spikes. During the backpropagation and refractory periods the soma is set to its clamp value before the first stage and does not move in the Euler prediction of the second, and the dendrites follow the same Heun update. The synaptic currents are evaluated at the stage potentials (the Euler-predicted potentials at the second stage), and the conductances are advanced with the exact one-step update of the double exponential (see ReceptorSynapse; PaperScheme keeps the discrete update of the published code).

SNNModels.TripodPaper — Method
TripodPaper(; N = 100, physiology = :human, config = :distal_proximal, d = 4um, VFT = Vector{Float32}, kwargs...) -> Tripod

Tripod population configured as the model of the published code of Quaresima et al. (2023), "The Tripod neuron: a minimal structural reduction of the dendritic tree", J. Physiol. (preprint bioRxiv 10.1101/2022.09.05.506197), repository aquaresima/tripod_neuron at commit 8698e1a (the paper release; src/TripodNeuron.jl/src/model/*.jl and simulator/simulation.jl). The parameters follow that code, not the preprint where the two differ (audit in validation/tripod_audit of the JuliaSNN publication repository). Use dt = 0.1ms in sim!/train!: the refractory lengths and the numerics are those of the original at that step; other steps give a warning (once).

Keywords

  • physiology::Symbol = :human: :human (human_dend, TripodDendSynapsePaper) or :mouse (mouse_dend, TripodDendSynapsePaperMouse: dendritic AMPA τr 0.25 / NMDA τr 0.99, τd 100, g0 0.159 ms/nS, DuarteGluDend).
  • config::Symbol = :distal_proximal: dendrite lengths of d1 and d2: :distal_distal (400, 400 um), :proximal_proximal (150, 150), :distal_proximal (400, 150; the default of the original code, its protocols stimulate d1), :proximal_distal (150, 400) or :soma_only (both dendrites disconnected; a point-neuron control: the original also routes the dendritic inputs to the soma, here connect the inputs to :s).
  • d = 4um: dendrite diameter. VFT = Vector{Float32}: state type (the original is Float32; Vector{Float64} runs the same scheme in double precision).
  • kwargs...: any other Tripod field (name, adex, spike, soma_syn, dend_syn, v_s, ...) replaces the value below.

TripodPaper

TripodPaper(; N = 100, physiology = :human, config = :distal_proximal, d = 4um, kwargs...) is a Tripod with the parameters and the integration scheme (PaperScheme) of the original code (aquaresima/tripod_neuron, commit 8698e1a). physiology is :human or :mouse; config is :distal_distal, :proximal_proximal, :proximal_distal, :distal_proximal or :soma_only; kwargs replace any Tripod field. Multipod

Multipod is the Tripod model with any number of dendrites: an AdEx soma and N_d passive dendrites, each attached to the soma (star topology), with the equations, synapse models, spike rules and integration schemes of Tripod. With N_d = 2 it is the Tripod model, with the same trajectory bit for bit. Reference and integration: as Tripod.

using SpikingNeuralNetworks
SNN.@load_units
param = SNN.MultipodParameter(ds = [400um, 250um => 3um, (150um, 300um)])   # length, length => diameter, or a (min, max) range
M = SNN.Multipod(N = 10, param = param)
E = SNN.Poisson(N = 50, param = SNN.PoissonParameter(20Hz))
syn = SNN.SpikingSynapse(E, M, :glu, :d3; conn = (p = 0.2, μ = 2.0))
  • Constructors: Multipod(; N, param, ...) or Multipod{D}(; ...); MultipodParameter(; ds, physiology, d, El_dend) builds the morphology (the star is the only geometry); MultipodPaper(; N, lengths, ...) is the preset of the integration scheme and parameters of TripodPaper for any number of dendrites.
  • Targets: the soma :s and the dendrites :d1, ..., :dN (fourth argument of SpikingSynapse).
  • Size: 1 to 64 dendrites. The types for 1 to 8 are defined when the package is loaded, the constructor defines the others (declare_multipod(D)); load_model and SNNload declare the types found in a file. Other readers of a saved file (JLD2.load) need declare_multipod(D) first.
  • set_dendrite_length!(M, k, l; neurons) changes the length of dendrite k for some neurons; l = 0um leaves an inert dendrite: isolated from the soma, it relaxes to its leak reversal with a 1 ms time constant, and still costs the same per step (use a Multipod with fewer dendrites to save it).
  • Synapses: MultiReceptorSynapse models are supported (the third argument of SpikingSynapse is then a receptor group, e.g. :NMDA; a group that the compartment does not have raises an error). PaperScheme (and MultipodPaper) needs ReceptorSynapse models and does not accept MultiReceptorSynapse.

SNNModels.Multipod — Method
Multipod(; N = 100, param = MultipodParameter(), adex = AdExParameter(),
           soma_syn = TripodSomaSynapse, dend_syn = TripodDendSynapse, spike = PostSpike(), scheme = HeunScheme(), ...)
Multipod{D}(; ...)

Population of neurons with an AdEx-like soma and $N_d$ passive dendrites d1, ..., dN ($1 \le N_d \le 64$), each attached to the soma through its axial conductance (star topology). The number of dendrites is length(param.ds); the population is an object of the concrete type Multipod<N_d> (SNNModels.Multipod3, ...), a subtype of Multipod{N_d}. ndendrites(p) returns $N_d$. The types for 1 to 8 dendrites are defined when SNNModels is loaded; for more, the constructor defines the type (declare_multipod), and load_model/load_data declare the types found in the file.

With $N_d = 2$ it is the Tripod model: same equations, synapses, spike rules and integration schemes, and the same trajectory bit for bit (potentials, adaptation, threshold, refractory counters and spike times) for the same parameters and initial state, with HeunScheme (Tripod) and PaperScheme (TripodPaper, see MultipodPaper).

Connections select the compartment with the fourth argument of SpikingSynapse: SpikingSynapse(pre, M, :glu, :d3; conn), targets :s, :d1, ..., :dN. With MultiReceptorSynapse models (soma_syn, dend_syn) the third argument is a receptor group (the target of its receptors, e.g. SpikingSynapse(pre, M, :NMDA, :d3; conn)); a group or buffer that the synapse model of the compartment does not have raises an ArgumentError. PaperScheme needs ReceptorSynapse models (the published scheme uses their legacy update, exact = false); HeunScheme accepts any synapse model with a five-argument synaptic_current!.

Equations

Those of Tripod with the sum of the axial currents over the $N_d$ dendrites. Soma (parameters from adex), and for each dendrite $k = 1, \dots, N_d$:

\[\begin{aligned} C \frac{dV_s}{dt} &= g_L (E_L - V_s) + g_L \Delta_T\, e^{(V_s - \theta)/\Delta_T} - w_s - I_{syn,s} - \sum_{k=1}^{N_d} g_{ax,k}\,(V_s - V_{d,k}) + I \\ C_{d,k} \frac{dV_{d,k}}{dt} &= g_{m,k} (E_{L,k} - V_{d,k}) - I_{syn,d,k} + g_{ax,k}\,(V_s - V_{d,k}) + I_d \\ \tau_w \frac{dw_s}{dt} &= a (V_s - E_L) - w_s \\ \tau_A \frac{d\theta}{dt} &= V_t - \theta \end{aligned}\]

The axial currents are summed in the order $k = 1, \dots, N_d$. $C_{d,k}$, $g_{m,k}$, $g_{ax,k}$ come from the length and diameter of dendrite $k$ (create_dendrite: $g_{ax} = \pi d^2 / (4 R_i l)$, $g_m = \pi d l / R_d$, $C = C_d \pi d l$); $E_{L,k}$ is param.El_dend, or adex.El at construction when it is nothing. The synaptic currents are clamped to $\pm 1500$ pA. $I_d$ is injected into every dendrite. The exponential term is $+g_L \Delta_T e^{(V_s - \theta)/\Delta_T}$, as in Tripod and the AdEx model.

Disconnected dendrites. A dendrite of length 0 (in param.ds, or for some neurons with set_dendrite_length!) has g_{ax} = 0, g_m = 1 nS, C = 1 pF: it is integrated like the others but isolated from the soma (its axial current is 0, so the soma and the other dendrites follow exactly the population without it; a Multipod with lengths [400um, 150um, 0um, 0um] gives the trajectory of Tripod with [400um, 150um] bit for bit). It keeps its receptors and input buffers; a SpikingSynapse onto it is accepted with a warning, and its inputs change only the potential of that dendrite. It costs the same time per neuron-step as a connected dendrite (the neuron loops are vectorised over neurons, all dendrite blocks are computed for every neuron); to save the time, use a population with fewer dendrites (e.g. Multipod{2} for neurons with two dendrites).

Spike, backpropagation and refractory period, and the integration: as in Tripod (see its Spike and Integration sections) for scheme = HeunScheme(), and as in PaperScheme for scheme = PaperScheme(), where the axial current of each dendrite is frozen over the step and the soma takes its two-stage step with the sum of the frozen axial currents.

Fields

The fields of Tripod, with one field per dendrite where Tripod has d1, d2:

  • id, name = "Multipod", N, records; param::DendNeuronParameter = MultipodParameter(...) (default: $N_d$ dendrites of length drawn in 200-400 um); adex, soma_syn, dend_syn, spike, Vspike = 0mV, scheme = HeunScheme().
  • d1, ..., dN::Dendrite: cable constants of each dendrite.
  • v_s, v_d1, ..., v_dN: compartment potentials (mV); w_s: adaptation current (pA); I: somatic current; I_d: current injected into each dendrite (pA); fire, spikes, tabs, θ.
  • synvars_s, synvars_d1, ...: synaptic state variables; receptors_s, receptors_d1, ...: input buffers.
  • Δv, Δv_temp (N x (N_d + 2): v_s, v_d1..v_dN, w_s), is, v_pred (N x (N_d + 1)): work arrays.

VFT = Vector{Float64} gives a Float64 population, as for Tripod.

Example

using SpikingNeuralNetworks
SNN.@load_units

SNNModels.MultipodParameter — Method
MultipodParameter(; ds = [(200um, 400um), (200um, 400um), (200um, 400um)], physiology = human_dend, d = 4um,
                    El_dend = nothing, geometry = [(:s=>:d1), ..., (:s=>:dN)]) -> DendNeuronParameter

Morphology of a Multipod neuron: a soma and N_d = length(ds) dendrites (1 <= N_d <= 64), named d1, ..., dN, all attached to the soma.

Keywords

  • ds: one entry per dendrite: a length (cm, e.g. 300um), a (min, max) range from which the length of each neuron is drawn, or length => diameter (a per-dendrite diameter, e.g. 300um => 3um).
  • physiology::Physiology = human_dend: cable constants Ri, Rd, Cd, common to all dendrites.
  • d = 4um: dendrite diameter, a number (all dendrites) or a vector with one diameter per dendrite (then every entry of ds becomes length => d[k], and param.d keeps the default 4 um, unused).
  • El_dend = nothing: dendritic leak reversal (mV); nothing: the somatic adex.El at construction (see Tripod).
  • geometry: the star [(:s=>:d1), ..., (:s=>:dN)], the only topology implemented; any other value raises an error.

The cable constants of dendrite k are those of create_dendrite (the formulas of Tripod): with length l and diameter d, $g_{ax} = \pi d^2 / (4 R_i l)$, $g_m = \pi d l / R_d$, $C = C_d \pi d l$. The returned DendNeuronParameter has type = MultipodNeuron(), so that Population(param) builds a Multipod for any number of dendrites.

using SpikingNeuralNetworks
SNN.@load_units
param = SNN.MultipodParameter(ds = [400um, 250um => 3um, (150um, 300um)])

SNNModels.declare_multipod — Method
declare_multipod(D::Integer) -> Type

Define the concrete population type SNNModels.Multipod<D> (a Multipod with D dendrites, 1 <= D <= 64) if it does not exist yet, and return it. Calling it again returns the existing type.

The types for 1 to 8 dendrites are defined when SNNModels is loaded. For more dendrites:

  • Multipod(; param) and Multipod{D}(; ...) declare the type themselves;

SNNModels.MultipodPaper — Method
MultipodPaper(; N = 100, lengths = [400um, 150um], physiology = :human, d = 4um, VFT = Vector{Float32}, kwargs...) -> Multipod

Multipod population configured as the model of the published Tripod code (the parameters, receptors, spike rules and PaperScheme of TripodPaper), with one dendrite per entry of lengths (fixed lengths, star topology). With two lengths it is TripodPaper with these lengths (bit for bit; lengths = [400um, 150um], the default, is TripodPaper(), configuration :distal_proximal). Use dt = 0.1ms in sim!/train! (other steps give a warning, once).

Keywords

  • lengths: dendrite lengths (cm, e.g. [400um, 250um, 150um]), 1 <= length(lengths) <= 64; 0um gives a disconnected dendrite (as soma_only of TripodPaper).
  • physiology::Symbol = :human: :human (human_dend, TripodDendSynapsePaper) or :mouse (mouse_dend, TripodDendSynapsePaperMouse).
  • d = 4um: dendrite diameter, a number or one diameter per dendrite.
  • VFT = Vector{Float32}: state type (Vector{Float64} runs the same scheme in double precision).
  • kwargs...: any other Multipod field (name, adex, spike, soma_syn, dend_syn, v_s, ...) replaces the preset value.

The somatic parameters, spike shape, refractory period, receptors and NMDA block are those listed in TripodPaper; the dendritic leak reversal is fixed at -70.6 mV (El_dend), and all compartments start at -70.6 mV with w = 0.

for _ in 1:3000
    SNN.integrate!(M, M.param, 0.1f0)         # dt = 0.1 ms

SNNModels.BallAndStick — Type
BallAndStick(; N = 100, param = BallAndStickParameter(), adex = AdExParameter(),
               soma_syn = TripodSomaSynapse, dend_syn = TripodDendSynapse, spike = PostSpike(), ...)

Population of two-compartment neurons: an AdEx-like soma coupled to one passive dendrite (d) through an axial conductance. Same equations, spike rule and Heun integration as Tripod with a single dendrite (during the backpropagation and refractory periods the soma is clamped and the dendrite is integrated in full, with leak and synaptic currents; before SNNModels 2.1 it only relaxed towards the soma); the synaptic currents are clamped to $\pm 1000$ pA and the external currents are Is (soma) and Id (dendrite). The dendrite diameter is param.d. Connections select the compartment with the fourth argument of SpikingSynapse: targets :s and :d.

Fields

Population info

  • name::String = "BallAndStick", id::String = randstring(12), N::IT = 100, records::Dict.

Parameters

  • param::DendNeuronParameter = BallAndStickParameter(): morphology.
  • adex::SOMAT = AdExParameter(): somatic parameters (see Tripod).
  • dend_syn::SYND = TripodDendSynapse, soma_syn::SYNS = TripodSomaSynapse: synapse models.
  • spike::PST = PostSpike(): spike shape and refractoriness.

Synapses

  • synvars_s, synvars_d: synaptic state variables; receptors_s, receptors_d::NamedTuple: input buffers.

Work arrays

  • Δv, Δv_temp::MFT (N x 3): derivatives of (v_s, v_d, w_s); is::MFT (N x 2); ic::VFT (length 1): unused, kept for compatibility; v_pred::MFT (N x 2): stage potentials of soma and dendrite.

SNNModels.create_dendrite — Method
create_dendrite(N::Int, l; El = -70.6mV, d = 4um, physiology = human_dend, FT = Float32) -> Dendrite
create_dendrite(l; d = 4um, physiology = human_dend) -> NamedTuple
create_dendrite(; l, kwargs...)

Compute the passive parameters of a cylindrical dendrite of length l and diameter d from the cable properties physiology (Physiology).

l is either a length (cm, e.g. 200um) or a tuple (lmin, lmax), in which case the length is drawn uniformly from lmin:1um:lmax (independently for each of the N neurons in the first form). Lengths above 1000um raise an error: this is a guard against a length given without its unit (400 is 400 cm), not a physical limit; up to SNNModels 2.0 the bound was 500um, which excluded the 550 um dendrites of the Tripod paper (Fig. 3). For l > 0 it returns (gm = G_mem(Rd, d, l), gax = G_axial(Ri, d, l), C = C_mem(Cd, d, l), l, d); for l <= 0 it returns a disconnected compartment (gm = 1, gax = 0, C = 1, l = -1, d). The N form returns a Dendrite{Vector{FT}} with these values per neuron and leak reversal El.

Precision: with FT = Float32 the geometry is computed with the Float32 unit constants. With FT = Float64 it is computed from the decimal values the arguments denote (5um, stored as 0.00049999997f0, is read as 0.0005; the cable constants likewise in their units). A range is sampled with the same RNG draws as in Float32, so the same seed gives the same lengths in both precisions.

Example

using SpikingNeuralNetworks
SNN.@load_units
SNN.create_dendrite(200um)                          # one dendrite, human physiology
SNN.create_dendrite(5, (150um, 400um); physiology = SNN.mouse_dend)

SNNModels.set_dendrite_length! — Method
set_dendrite_length!(p, k::Integer, l; neurons = 1:p.N, d = nothing) -> p

Set the length of dendrite k (d1, d2, ... of Tripod and Multipod; k = 1 is d of BallAndStick) of the neurons neurons of population p to l (cm, e.g. 250um, or a (min, max) range drawn per neuron), and recompute its cable constants with create_dendrite (the physiology of p.param, the diameter d, by default the current diameter of each neuron). The leak reversal El and the state are not changed. p.param.ds keeps the lengths given at construction.

l = 0 disconnects the dendrite of these neurons: g_ax = 0, g_m = 1 nS, C = 1 pF and l = -1 (the values of create_dendrite for l <= 0). Such a dendrite is still integrated, isolated from the soma: it relaxes to its leak reversal with a time constant of 1 ms, its synaptic inputs and I_d change its potential but do not reach the soma, and the soma does not see it (its axial current is 0). The cost per neuron-step is the one of a connected dendrite; a population without these dendrites (Multipod with fewer dendrites, e.g. Multipod{2} for interneurons) is the way to save it.

Example

using SpikingNeuralNetworks
SNN.@load_units
M = SNN.Multipod(N = 100, param = SNN.MultipodParameter(ds = [400um, 300um, 200um, 150um]))
SNN.set_dendrite_length!(M, 4, 0um; neurons = 51:100)     # neurons 51-100: three dendrites

SNNModels.DendNeuronParameter — Type
DendNeuronParameter(; ds = [(200um, 400um), (200um, 400um)], physiology = human_dend, d = 4um, El_dend = nothing,
                      geometry = [(:s=>:d1), (:s=>:d2)], type = <from length(ds)>)

Parameter struct of the multicompartment dendritic populations (Tripod, BallAndStick, Multipod). It carries the morphology only; the somatic parameters are in the population field adex (an AdExParameter) and the synapses in soma_syn/dend_syn.

Population(param::DendNeuronParameter; kwargs...) builds a Tripod when type is TripodNeuron(), a BallAndStick when it is BallAndStickNeuron() and a Multipod when it is MultipodNeuron().

Fields

  • ds::DT = [(200um, 400um), (200um, 400um)]: one entry per dendrite, either a length (cm, any Real, stored as Float32) or a (min, max) range from which create_dendrite draws the length of each neuron. Multipod also accepts length => diameter (the length a number or a range), the diameter of that dendrite replacing d.
  • physiology::PT = human_dend: cable properties (Physiology: Ri, Rd, Cd), used by Tripod and BallAndStick to build their dendrites.
  • d::Float32 = 4um: dendrite diameter (cm), common to all dendrites of the neuron. It enters the cable formulas of create_dendrite: g_ax ∝ d², g_m ∝ d and C ∝ d at fixed length. The default is the 4 um of the published model.
  • El_dend::Union{Nothing,Float32} = nothing: leak reversal potential of the dendrites (mV). nothing (default): the dendrites use the somatic adex.El. A number: create_dendrite(...; El = El_dend), so the dendritic leak stays fixed whatever the somatic El (the original Tripod fixes it at -70.6 mV). It is read once, when the Tripod/BallAndStick is constructed (Dendrite.El); with nothing, changing adex.El afterwards does not move the dendritic leak either (it keeps the value adex.El had at construction), see Tripod.
  • geometry::GT: connectivity of the compartments, [(:s=>:d1), (:s=>:d2)] for one or two dendrites and the star [(:s=>:d1), ..., (:s=>:dN)] for more. Stored for bookkeeping; the populations hard-code the soma-dendrite coupling (all dendrites attached to the soma).
  • type::NT: BallAndStickNeuron() if length(ds) == 1, TripodNeuron() if length(ds) == 2, MultipodNeuron() if 3 <= length(ds) <= 64 (MultipodParameter sets MultipodNeuron() for any number of dendrites); other lengths raise an error.

Type parameters: ET = Union{Nothing,Float32}, DT = Vector{DendLength} (DendLength = Union{Float32,Tuple}), GT = Vector{Pair{Symbol,Symbol}}, PT = Physiology{Float32}, NT<:AbstractDendriticTree.

Example

using SpikingNeuralNetworks
SNN.@load_units
param = SNN.DendNeuronParameter(ds = [(150um, 300um), (300um, 400um)], physiology = SNN.mouse_dend)
T = SNN.Population(param; N = 10)   # a Tripod

SNNModels.synaptic_target — Method
synaptic_target(targets::Dict, post::AbstractDendriteIF, sym::Symbol, target::Symbol)

Target the receptor buffer post.receptors_<target>.<sym> of compartment target (:s, :d1, :d2 for Tripod; :s, :d for BallAndStick; :s, :d1, ..., :dN for Multipod); sym is mapped with get_synapse_symbol (:ge/:he -> :glu, :gi/:hi -> :gaba).
